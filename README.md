# liri-dev

Personal portfolio for Lirije Shabani, fullstack developer.

Built with React, TypeScript, Vite, Tailwind CSS, shadcn/ui and Framer Motion.

## Structure

- `src/components/` – page sections (About, Projects, Experience, Skills, Education, Contact)
- `src/data/projects.ts` – project content shown in the cards and detail view
- `src/types/project.ts` – the project data model
- `public/` – project screenshots and diagrams

## Development

```sh
npm install
npm run dev     # start the dev server
npm run build   # production build
npm test        # run tests
```
